# Descriptive Analytics Report

## 📌 Project Overview
This project focuses on Descriptive Analytics using IBM Cognos Analytics.
It analyzes retail sales data to identify sales trends, regional performance,
product category performance, and customer insights.

## 🎯 Project Objectives
- Analyze retail sales data using descriptive analytics.
- Compare sales performance across different regions.
- Identify top-performing product categories.
- Summarize sales and quantity using reports and crosstabs.
- Present meaningful insights through data visualization and reporting.

## 🛠️ Tools & Technologies
- IBM Cognos Analytics
- Microsoft Excel
- Data Visualization
- Descriptive Analytics
